# 부산 한걸음의 함께

부산광역시사회서비스원 주관 경계선지능인 사업 홈페이지 **제작 시안**입니다. 공식 기관 승인·공식 사이트 지위를 의미하지 않습니다.

## 실행

`index.html`을 두 번 클릭하면 열립니다. 외부 패키지 설치나 빌드 없이 사용합니다. 모든 파일과 `assets` 폴더를 함께 보관하세요.

## 구성

메인 이름: **부산 한걸음의 함께**. 첫 화면 아래 항목을 선택하면 해당 구역으로 이동합니다. 스크롤 중에도 구역 메뉴가 유지됩니다. 휴대전화에서는 항목 메뉴를 좌우로 넘길 수 있습니다.

온라인 글꼴은 Google Fonts에서 로드하며 오프라인에서는 기본 한글 글꼴을 사용합니다.

- 캠페인 중심 첫 화면과 독창적으로 생성한 부산 일러스트
- 세로 스크롤형 캠페인: 큰 메인 제목과 화면 전체 이미지, 하단 항목 메뉴, 구역별 부드러운 스크롤 이동과 현재 위치 표시
- 부산사회서비스원 사업 소개, 타 기관 소개와 지역 필터
- 청년 / 아동·청소년 / 부모·보호자 / 기관·종사자별 신청 안내
- 자료·정보, 이용 안내 및 체크리스트 다운로드
- 당사자·보호자 게시판과 건의문 작성 화면
- 휴대전화 대응, 키보드 접근, 큰 글씨 보기

## 실제 운영 기능과 구분

현재 파일은 GitHub Pages에서 실행되는 정적 홈페이지입니다.

- 신청은 공식 기관 홈페이지로 연결됩니다. 직접 접수하거나 개인정보를 수집하지 않습니다.
- 확인되지 않은 모집 일정이나 아동·보호자 대상 사업을 임의로 만들지 않았습니다.
- `config.js`의 대상별 빈 URL을 운영기관이 확정한 **HTTPS 공식 접수 URL**로 바꾸면 신청 버튼이 그곳으로 연결됩니다.
- 게시판/건의문은 미리보기·다운로드·선택적 기기 초안 저장 기능입니다. **공동 게시·실제 전송·로그인·관리자 기능은 없습니다.**
- 초안은 해당 브라우저의 localStorage에만 저장됩니다. 브라우저 데이터를 지우면 없어집니다. 공용 PC에는 초안을 남기지 마세요.
- 공동 게시판을 운영하려면 서버/데이터베이스, 회원 인증, 이용자 구분, 게시물 신고·관리, 권한 검증, 개인정보 처리방침, 보관·삭제 정책을 별도로 구현해야 합니다. GitHub Pages 자체는 이를 제공하지 않습니다.
- 실제 건의 접수에는 승인된 접수 URL 또는 서버 연동이 필요합니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더 **안의 파일들**을 저장소 최상위에 올립니다. `index.html`이 최상위에 있어야 합니다.
3. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. `main` 브랜치, `/(root)`를 선택하고 저장합니다.
5. GitHub가 생성하는 Pages 주소를 확인합니다.

상대 경로를 사용하므로 저장소 이름을 바꾸어도 하위 경로에서 실행할 수 있습니다. `.nojekyll`도 포함했습니다.

## 운영 전 확인

기관 명칭/공식 로고 사용 승인, 사업별 최신 공고, 접수 URL, 연락처, 개인정보 안내, 접근성과 실제 서버 연동을 확인해야 합니다. 현재 이미지는 캠페인용 창작 일러스트로 실제 참여자 사진이 아닙니다.
